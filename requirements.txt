# 「在任何人机器上都能跑」的差别就是这份文件里有没有 ==）；唯一例外是 playwright，见下方说明。

# ---- Web 层 ----------------------------------------------------------------
fastapi==0.141.1
uvicorn[standard]==0.54.0

# ---- 数据层 ----------------------------------------------------------------
sqlalchemy==2.0.54
# ↑ 2.1 已发布，但网上教程和 AI 生成的代码全是 2.0 写法（DeclarativeBase / Mapped[] / mapped_column），
#   为一个作品集项目去趟 2.1 的浑水不划算。

# ---- 采集层 ----------------------------------------------------------------
httpx==0.28.1
# ↑ 用 httpx 而不是 requests：采集层跑在 async worker 里，requests 同步会堵死事件循环。

# ---- 数据处理 --------------------------------------------------------------
numpy==2.5.2
# ↑ 自己直接 import 的库必须自己钉版本：seed.py 用它做对数正态/幂律采样，靠 pandas 传递安装的话，
#   哪天 pandas 改了依赖声明会立刻 import 失败，而报错现场在数据生成、不在依赖清单。

pandas==3.0.3
# ↑ 只用于 export（CSV/Excel）。清洗层刻意不用它：pandas 3.0 字符串 dtype 变 str、None 被强制转 NaN、
#   教程全是 2.x 写法，而清洗是逐条字符串解析、用不上向量化——原因见 docs/可行性评估.md。

openpyxl==3.1.5
# ↑ pandas.to_excel 的引擎，不显式依赖的话 Excel 导出会在运行时才报错。

matplotlib==3.11.2
# ↑ 它不是"画演示图的可选工具"，而是开发期自检工具：spike/plot_seed.py 的三张图是发现数据 bug 的主要手段
#   （累乘漂移、大促日被跳过都是图上先看出来的，统计指标当时全"正常"），所以是硬依赖不是 dev 依赖。
#   两个坑（plot_seed.py 已处理）：先 use("Agg") 再 import pyplot；必须设中文字体，否则中文全变方框。

# ---- 配置 / 中文处理 -------------------------------------------------------
python-dotenv==1.2.3

jieba==0.42.1
# ↑ 中文分词，词云用。

setuptools<81
# ↑ 删掉项目就跑不起来：jieba 的 _compat.py 仍写着 import pkg_resources，
#   而 setuptools 82（2026-02 发布）已把它整个删除；症状像 jieba 装坏了，其实是 setuptools 太新。

# ---- AI 分析 ---------------------------------------------------------------
openai==3.5.0
# ↑ 用 OpenAI SDK 指向智谱的 OpenAI 兼容端点，不引 zhipuai / zai-sdk：同一套代码改三个环境变量
#   就能切 Ollama / SiliconFlow，不被单一供应商锁死（代价是官方 SDK 的校验更准，是取舍不是更好）。
#   注意 glm_client.py 是函数体内惰性 import，"没装 openai"在模块加载时不暴露——依赖清单必须由人记住。
#   它拉的是独立的 httpx2 包，不影响上面钉死的 httpx==0.28.1（已实测）。

# ---- 定时任务 --------------------------------------------------------------
apscheduler==3.11.3
# ↑ 不要升 4.x：至今只有 4.0.0a6 这种 alpha 版本，官方 README 明写着「请勿用于生产」。

# ---- 采集降级层（可选）-----------------------------------------------------
playwright>=1.48
# ↑ 注意：装包 ≠ 装浏览器（pip install 只装几 MB 的库，还要 playwright install chromium 下约 150MB）。
#   本项目 SMZDM 页面是服务端渲染、httpx 就够用，Playwright 只是分层降级链的最后一层——现在不要装 chromium。
#   用 >= 而非 ==：playwright 对 Python 版本有要求（3.13 需要 >=1.48），允许它往上走一点比钉死更稳妥。

# ---- 测试 ------------------------------------------------------------------
pytest==9.1.1
